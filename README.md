Proyecto SQL
Descripción
Ejercicio final del módulo de SQL del master Data Analytic, en el que se han formulado 64 consultas para obtener información sobre alquileres de películas
Estructura
En el repositorio se encuentra la información del proyecto y las 64 consultas del mismo
Requisitos
Para poder llevar a cabo el proyecto se necesitan las siguientes herramientas:
* DBeaver: es una herramienta de administración de bases.
* PostgreSQL: es un sistema de gestión de bases de datos relacional de código abierto.
* GitHub: es un repositorio de información.
Resultados y conclusiones
Durante las 64 consultas se han puesto en uso muchas de las funciones de SQL aprendidas en el módulo como por ejemplo:
* Consultas básicas: select, from, where y as
* Consultas de agregación: Min, Max, Count, Sum, AVG, Variance, STDDEV y Concat
* Consultas de ordenación y agrupación: Order by, Limit, Offset, Group By y Having
* Relaciones entre tablas: Inner Join, Left Join, Right Join, Cross Join, Full Join
* Subconsultas: con Where, con Where (Exist y Not Exist), con Select y con From
* Estructura de datos persistentes: Vistas
* Estructuras de datos temporales: CTEs intro, CTEs antes de Select, CTEs al comiendo de una subconsulta, CTEs entre dos Selects y Tablas Temporales
Esquema de la Base de Datos
La base de datos de este proyecto contiene información de películas, actores, categorias de películas, alquileres, clientes, trabajadores y tiendas
El esquema completo es el que se encuentra en el repositorio
